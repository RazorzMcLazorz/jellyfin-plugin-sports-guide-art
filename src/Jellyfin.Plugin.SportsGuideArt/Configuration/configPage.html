Sports Guide Art

Fills Live TV programs that have no art. It tries, in order: the same title on the same channel, the same title on another channel, art remembered from earlier guide refreshes, then a generated matchup image.

Matching

Labels such as Upcoming or Pregame followed by :, - or |. "Upcoming: A vs B" then matches "A vs B".

Generated matchup images

Only for titles like "Team A vs Team B" (also "v", "@", "at").
Paths from ESPN's site API, e.g. hockey/nhl, soccer/eng.1.
123 is the free key (rate-limited). Paid keys from thesportsdb.com remove the limit.

Running and cache

A guide refresh removes art the provider did not send, so this keeps filled art in place.
Images are stored under the server's data folder in sports-guide-art. 0 keeps them forever.
